# PZ Cloud Coop — общий мир Project Zomboid через Яндекс Диск

**Версия 0.4-preview.** Экспериментальная утилита, не связанная с разработчиками Project Zomboid. Перед переносом основного мира проверьте всё на тестовом.

## Идея

Несколько друзей играют в один и тот же мир, по очереди становясь **хостом** («Хост» в меню PZ). Мир хранится на Яндекс Диске в общей папке:

- `snapshots/` — архивы всех версий мира (старые не удаляются);
- `latest.json` — какая версия последняя;
- `active.json` — кто сейчас хост (блокировка).

Хост нажимает **«Играть»**: программа скачивает последнюю версию, проверяет её, делает резервную копию и открывает игру. Когда хост полностью выходит из PZ, программа сама выгружает мир обратно, и следующим хостом может стать кто угодно.

## Быстрый старт для друзей

### 1. Скачать программу

- **Windows:** со страницы **Releases** репозитория скачайте `PZCloudCoop-windows.zip`, распакуйте в отдельную папку (не в папку игры и не в облако) и запустите `PZCloudCoop.exe`. Python не нужен.
  Windows SmartScreen может предупредить о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».
- **Linux:** `PZCloudCoop-linux.zip` из Releases, либо из исходников: `./Start_Linux.sh` (нужен Python 3 и tk: Arch `sudo pacman -S tk`, Ubuntu `sudo apt install python3-tk`).

rclone ставить не нужно: при первом подключении программа сама скачает официальную сборку с downloads.rclone.org и проверит её контрольную сумму.

### 2. Подключить Яндекс Диск

При первом запуске откроется окно «Подключить Яндекс Диск»:

1. **ClientID** уже заполнен, если владелец положил рядом с программой `pzcloud-defaults.json` (см. ниже). Иначе спросите его у владельца.
2. «Открыть Яндекс» → войдите в **свой** аккаунт → «Разрешить».
3. Яндекс покажет токен. Скопируйте его (или весь адрес страницы) в поле и нажмите «Подключить».

Токен хранится только у вас, в `rclone.conf` рядом с программой. **Никому его не пересылайте.** Он действует около года; срок показан в главном окне, обновляется той же кнопкой.

### 3. Настройки

- **Ваше имя** — увидят друзья в статусе.
- **Имя сервера** — то, что в PZ в меню «Хост» (по умолчанию `servertest`). **Одинаковое у всех.**
- **Папка в облаке** — `yadisk:PZ-Shared`. **Одинаковая у всех.**
- **Папка Zomboid** — подставляется автоматически (Windows `%USERPROFILE%\Zomboid`, Linux `~/Zomboid`, Linux + Proton — внутри `steamapps/compatdata/108600/...`).

### 4. Играть

1. Договоритесь в чате, кто сегодня хост. Статус «Сейчас играет» должен быть «никто».
2. Хост нажимает **«Играть — стать хостом»**. Откроется PZ → «Хост» → тот же профиль сервера. Друзья подключаются к хосту через Steam.
3. После игры хост **полностью выходит из PZ** и ждёт «ГОТОВО» в окне программы. Окно не закрывать!
4. Если «ГОТОВО» не появилось (программа не заметила игру — бывает со Steam/Proton), после выхода из игры нажмите **«Я закончил — выгрузить мир»**.

## Для владельца мира (один раз)

1. **Приложение Яндекса.** На https://oauth.yandex.ru создайте приложение с правами Яндекс Диска: «Чтение всего Диска», «Запись в любом месте на Диске», «Доступ к информации о Диске». Redirect URI оставьте по умолчанию (`verification_code`). Скопируйте **ClientID** — он не секретный, его можно дать друзьям. Client secret не нужен никому.
   (Стандартное подключение rclone к Яндексу с осени 2026 получает ошибку `410 Gone`, поэтому нужно своё приложение.)
2. **Общая папка.** На disk.yandex.ru создайте `PZ-Shared` и через «Настроить доступ» пригласите друзей с правом **«Редактирование»**. Друзья принимают приглашение у себя в «Общем доступе». Публичная ссылка не подходит.
3. **Файл для друзей.** Скопируйте `pzcloud-defaults.example.json` в `pzcloud-defaults.json`, впишите ClientID, имя сервера и папку и положите рядом с программой перед тем, как отправить её друзьям — тогда им останется ввести только своё имя.
4. **Первая публикация.** На компьютере, где уже есть мир (создан через «Хост» хотя бы раз), нажмите «Дополнительно → Первая публикация мира». Только у одного человека!

## Что синхронизируется

- `Zomboid/Saves/Multiplayer/<сервер>/` — сам мир, включая персонажей всех игроков.
- `Zomboid/Server/<сервер>.ini` и `<сервер>_*` — настройки сервера, песочницы, моды.
- `Zomboid/db/<сервер>.db` — аккаунты сервера.

Не синхронизируются личные клиентские папки `*_player` (исследованная карта, метки). При смене хоста игра может завести новую — проверьте на тестовом мире.

## Защита данных

- Перед установкой чужой версии — ZIP-копия вашего локального мира в `local-backups/`; после игры — ещё одна, даже если облако недоступно.
- Архив проверяется по SHA-256 при скачивании и по MD5 после загрузки; `latest.json` меняется только после проверки.
- Нельзя выгрузить мир, если в облаке появилась другая версия или блокировка не ваша.
- Программа ждёт закрытия не только окна игры, но и отдельного серверного процесса «Хоста», который дописывает мир после выхода.
- **Блокировка не атомарная.** Если двое нажмут «Играть» почти одновременно, защита может не сработать — поэтому договаривайтесь в чате.
- «Снять зависшую блокировку» — только когда в чате все подтвердили, что никто не играет.

## Если что-то пошло не так

| Сообщение | Что делать |
|---|---|
| `410 Gone` | Подключение без своего приложения Яндекса. Пересоздайте токен через «Подключить Яндекс Диск» с ClientID. |
| `401 Unauthorized` | Токен истёк или отозван — «Подключить Яндекс Диск» заново. |
| `TLS connect error` / `unexpected eof` | Сеть режет соединение с Яндексом: проверьте VPN/прокси. |
| «Мир занят» | Хостом сейчас кто-то другой. Дождитесь «ГОТОВО» у него. |
| «Контрольная сумма не совпала» | Мир не тронут. Повторите «Играть». |
| «Процесс игры не найден» | После игры нажмите «Я закончил — выгрузить мир». |

Откат на старую версию пока ручной: архивы лежат в `PZ-Shared/snapshots/`, локальные копии — в `local-backups/`.

## Для разработчиков

```
pzcloud.py        — вся логика + текстовое меню (python3 pzcloud.py, или ./Start_Linux.sh --cli)
pzcloud_gui.py    — окно на tkinter
Start_Linux.sh    — запуск из исходников на Linux
Start_Windows.cmd — запуск из исходников на Windows (нужен Python)
.github/workflows/build.yml — сборка .exe и Linux-бинарника; тег v* публикует Release
```
